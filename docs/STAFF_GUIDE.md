# Staff guide: running the sports room desk

Sign in with the account the admin gave you. A temporary password must be changed at first login.

## A normal day
**Approve a request** (menu: Approvals). A student asked for an item. Check the student's face or ID, pick the
exact unit from the list, press Approve. The timer starts. A request nobody answers within the approval time
expires by itself and the student must ask again.

**Reject a request.** Press Reject and write a short reason (item not available, ground closed...). The student sees it.

**Confirm a return** (menu: Returns). The student pressed Return. Check the unit code shown in big letters
against the item in your hand, choose its real condition, then press Confirm return. Never confirm without seeing the item.

**Wrong item brought back.** If the code on the item is not the one issued, press "Flag mismatch" and write what you
see (for example "The ball says FB-012"). The return stays open and the admin can see the flag. Do not confirm it.

**Damaged on return.** Choose condition "Damaged", add a damage note, press "Confirm and report damage".
The unit leaves the available list and an admin decides: repaired, retired or lost.

**Overdue** (menu: Overdue). Lists everything past its time. Call or message the student. When they bring it back
confirm the return as usual; it is counted as a late return.

## Students who are stuck
- **Forgot password:** the student uses "Forgot password" with SRN or email and gets a link. The admin can also issue a temporary password from the Students page; the student must change it at first login.
- **Student cannot log in at all:** check SRN spelling with the admin; accounts exist only for imported students.
- **Item says "with a student" but it is on the shelf:** it was never confirmed back. Confirm the return in Returns.

## Stock count (menu: Stock count)
Start a count, scan or tick every unit you find on the shelves, then finish. The system lists units it
expected but you did not find. Check those twice before marking them missing. Do a count at least once a term.

## What staff cannot do
Resolve damage reports, change equipment, import students, open the Students report CSV and the audit log: those are admin only.

## When something looks wrong
 Note the unit code and time, and tell the admin.
